# 3d-model-generation

An [Agent Skill](https://skills.sh) for turning text prompts or images into 3D meshes — tools, export formats, and how to use them in Blender / Unity / three.js.

```
npx skills add <your-github-user>/3d-model-generation
```

## What it does

- **Generation** — text/image → GLB/OBJ/USDZ
- **Export & import** — Blender, Unity, three.js snippets
- **Quality tips** — multi-view, topology, texture
- **Limits** — when AI meshes need cleanup

See [`SKILL.md`](./SKILL.md) for the full instructions.
